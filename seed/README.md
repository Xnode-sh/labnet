# Набор выживания — что кладём в Ковчег

Это стартовое знание, которое едет с сетью с первого запуска. Только проверенные,
общепринятые basics. **Перед применением сверяйся с официальными источниками и
специалистом** — особенно в медицине.

- `water.md` — вода
- `first-aid.md` — первая помощь
- `food.md` — еда
- `power.md` — энергия
- `radio.md` — связь и сигналы
- `shelter-fire.md` — укрытие и огонь

Загрузка в Ковчег: `bash install/seed-ark.sh`.
