# RUNBOOK — поднять сеть судного дня с нуля

Короткая инструкция для человека, у которого нет интернета, серверов и времени.
Всё работает **оффлайн**, между своими устройствами.

## 1. Поставить

```bash
pkg install python python-cryptography git
git clone <labnet> ~/labnet && cd ~/labnet
export LABNET_PASSPHRASE='свой-секретный-пароль'   # одинаковый на всех устройствах
python labnet.py --share ~/labnet-share init --name ИМЯ --net КОВЧЕГ
```

## 2. Первый контакт

**Если рядом Wi-Fi (общий роутер или хотспот телефона):**

```bash
python labnet.py daemon        # само найдёт своих, поздоровается, синхронит
```

**Если радио нет — несите на носителе (флешка/SD):**

```bash
# на устройстве A
python labnet.py send <имя-получателя> "текст"   # очередь копится
python labnet.py pack /sdcard/carrier.tar.gz      # собрать носитель

# перенести файл на устройство B (физически), затем:
python labnet.py unpack /sdcard/carrier.tar.gz    # принять
```

## 3. Обмен знаниями (Ковчег)

```bash
python labnet.py ark put /path/doc.txt -n water   # положить знание
python labnet.py ark list                          # что есть
python labnet.py ark get water -o out.txt          # достать
```

Ковчег реплицируется сам при контакте (в демоне или при `connect`).

## 4. Чат

```bash
python labnet.py web            # откроется чат в браузере телефона (127.0.0.1)
python labnet.py chat           # чат в терминале
```

## 5. Проверить связь

```bash
python labnet.py discover --seconds 5   # кто рядом
python labnet.py peers                  # кто в сети
python labnet.py ping <имя>             # достучаться
python labnet.py queue                  # что ждёт отправки
```

## Правила выживания

- **Пароль сети** знают только свои; он нигде не хранится, вводится при запуске.
- **Никогда** не публикуйте пароль, `~/.config/labnet/identity.json` и содержимое Ковчега.
- Сообщения не теряются: нет связи — уйдут позже (храни-и-передай).
- Заряжайте носитель-телефон заранее; держите копию Ковчега на 2–3 устройствах.

## Частые вопросы

- **Никого не находит?** Убедитесь, что устройства в одной сети Wi-Fi и пароль одинаков.
- **`ping` не отвечает?** Узел спит — попробуйте позже или несите носитель.
- **Нет вибрации/уведомлений?** Нужно приложение Termux:API; без него всё остальное работает.
